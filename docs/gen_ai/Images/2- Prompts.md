## 📌 Overview
Not all prompts are equal — structured frameworks make ChatGPT (and other LLMs) give **better, clearer, and more useful outputs**.  

- **Best for Coding** → **RACE Prompt** (Role, Action, Context, Explanation)  
- **Best for Documentation** → **CARE Prompt** (Context, Action, Result, Example)  
- **Best for Emails / Writing** → **CREATE Prompt** (Character, Request, Examples, Adjustments, Type, Extras)  

Plain English prompts work, but frameworks help when you want **precision, consistency, and professional results**.

---

## 🧩 Prompt Frameworks

### 1. Standard Prompt
- **Use for**: Quick, general requests.  
- *Example*: "Write a LinkedIn post about our new product."

---

### 2. Reasoning Prompt
- **Use for**: Step-by-step problem solving, debugging, or analysis.  
- *Example*: "Given daily signup data, reason step-by-step and decide whether to increase ad spend."

---

### 3. RACE Prompt *(Role, Action, Context, Explanation)* ✅ Best for Coding
- **Use for**: Coding tasks, architecture, technical documentation.  
- *Example*: "Role: Python Data Engineer. Action: Write Spark job. Context: Input = Kafka stream. Explanation: Add comments for each step."

---

### 4. CARE Prompt *(Context, Action, Result, Example)* ✅ Best for Documentation
- **Use for**: Writing docs, clear outputs with examples.  
- *Example*: "Context: Data pipeline. Action: Create consumer code. Result: JSON → Parquet. Example: Show small dataset sample."

---

### 5. APE Prompt *(Action, Purpose, Execution)*
- **Use for**: Task execution with reasoning.  
- *Example*: "Action: Optimize loop. Purpose: Reduce runtime. Execution: Show improved Python code."

---

### 6. CREATE Prompt *(Character, Request, Examples, Adjustments, Type, Extras)* ✅ Best for Emails/Writing
- **Use for**: Professional writing, marketing, outreach.  
- *Example*: "Character: Marketing Manager. Request: Write email. Examples: Add 2 variations. Adjustments: Formal tone."

---

### 7. TAG Prompt *(Task, Action, Goal)*
- **Use for**: Quick coding or business tasks.  
- *Example*: "Task: Write SQL query. Action: Add filter. Goal: Return monthly sales."

---

### 8. CREO Prompt *(Context, Request, Explanation, Outcome)*
- **Use for**: Strategy, problem-solving, design.  
- *Example*: "Context: ETL pipeline. Request: Suggest design. Explanation: Why it works. Outcome: Reliable daily jobs."

---

### 9. RISE Prompt *(Role, Input, Steps, Execution)*
- **Use for**: Tutorials, teaching-style explanations.  
- *Example*: "Role: Tutor. Input: List of numbers. Steps: Explain sorting. Execution: Provide Python code."

---

### 10. PAIN Prompt *(Problem, Action, Information, Next Steps)*
- **Use for**: Debugging, troubleshooting.  
- *Example*: "Problem: Spark job failing. Action: Diagnose error. Info: Logs provided. Next Steps: Fix suggestions."

---

### 11. COAST Prompt *(Context, Objective, Actions, Scenario, Task)*
- **Use for**: Workflows, process automation.  
- *Example*: "Context: Kafka → Spark → S3. Objective: Real-time ETL. Scenario: Handle schema drift."

---

### 12. ROSES Prompt *(Role, Objective, Scenario, Expected Solution, Steps)*
- **Use for**: Complex systems, architecture, decision-making.  
- *Example*: "Role: Data Architect. Objective: Design pipeline. Scenario: CDC data ingestion. Expected Solution: Fault-tolerant system. Steps: Provide plan."
